How the method works

The planner compares task and repetition combinations that fit your budget:

  1. Published correlations show how well each task tracks the full DeepSWE benchmark.
  2. The bare model’s repeated runs provide score variation, cost, and available headroom.
  3. The planner favors relevant, stable tasks while respecting your budget and minimum task count.
  4. A result is labeled optimal only when the search proves no remaining plan can do better. Otherwise the result shows the remaining possible gap.

If the bare model’s repeated scores have zero variation, the planner may use variation from the same task under other published configurations. The plan labels that fallback.
