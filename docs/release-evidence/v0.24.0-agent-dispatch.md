## Observations

- The Muse dispatch records report `provider_version` `1.4.0`, while
  `muse --version` reports `1.4.3`. `~/.local/bin/muse` is a launcher script
  that updates the binary next to it without changing the launcher file. The
  dispatch capability cache keys provider identity on the launcher's
  path, inode, size, and mtime, so its cached `1.4.0` entry was reused. The
  probes ran the installed 1.4.3 binary.
- During the first four `al dispatch options` snapshots, Grok model discovery
  reported `grok model discovery: harness is not authenticated; sign in using
  al grok`. Grok stayed available, both Grok probes passed, and the snapshot
  taken after the Grok probe showed discovery succeeding (`source`
  `harness`). Sign-ins were not changed.
