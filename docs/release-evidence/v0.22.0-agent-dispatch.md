# Agent Dispatch v0.22.0 Compatibility Evidence

Date: 2026-09-21

Runner: local macOS checkout using a source build from the v0.22.0 candidate
commit (`go build ./cmd/al`). Provider probes ran in an isolated scratch
repository so provider tools could not modify the release checkout. The
scratch repo enabled all five dispatch targets; fresh `init` defaults leave
Antigravity, Grok, and Muse disabled. The scratch repo was git-initialized
because the Codex CLI refuses to run outside a trusted directory.

## Installed versions

- Claude Code: `2.1.278 (Claude Code)`
- Codex CLI: `codex-cli 0.155.1`
- Antigravity: `1.2.7`
- Grok CLI: `grok 1.0.24 (68e414c661e3) [stable]`
- Muse Code: `Muse Code 1.3.0 (1.3.0-R3401.1)`

`al dispatch options` reported all five providers available. The configured
source-built targets were Codex `gpt-6-astra` with medium reasoning, Claude
`opus[1m]` with high reasoning, Antigravity `gemini-3.8-flash-medium`, Grok
`grok-4.6` with high reasoning, and Muse `muse-spark-1.3` with xhigh
reasoning.

## Fresh and continuation probes

Each reachable provider received a fresh `start`/`wait` probe and a
`continue`/`wait` probe on the same handle. Antigravity and Muse were
reachable; the other three providers were blocked by external authentication
or quota state before any provider contact attributable to this release.

Both Antigravity terminal results contained exactly the requested token and
preserved the same provider session ID across fresh and continuation probes,
with provider usage evidence on each. Both Muse terminal results contained
exactly the requested token and preserved the same provider session ID
across fresh and continuation probes; the Muse provider event stream carried
no usage numbers in this run.

The first Codex fresh attempt failed before provider contact with `Not
inside a trusted directory and --skip-git-repo-check was not specified`
because the scratch repo was not yet a git checkout. After git-initializing
the scratch repo, the retry reached the provider and reported the external
usage limit above. No code change was involved.

Muse provider stderr reported only workspace-root and workspace-trust lines;
the `agentLayerManagedMcpServers` warning observed against the pre-rebuild
implementation did not appear in this run.
