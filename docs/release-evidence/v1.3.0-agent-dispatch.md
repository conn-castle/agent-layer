## Scope and limitations

This release changes development MCP snapshots and image-cache leases/pruning (#530, #525), provider-home selection used by dispatch and recovery (#518), and Grok model discovery (#421). The short CLI probes validate the fresh/continuation lifecycle under current sign-ins. They do not exercise MCP image handoff, concurrent cache pruning, or expired-credential refresh; those paths have separate automated coverage. These successful Antigravity probes exercise the v1.3.0 candidate with agy 1.5.9; they do not retroactively establish v1.2.1 compatibility requested by [#531](https://github.com/conn-castle/agent-layer/issues/531).

Raw probe reports, CLI versions, options, and the projection-restoration log are retained locally under `.agent-layer/tmp/release-v1.3.0/`; invocation records and native provider output are under `.agent-layer/tmp/runs/<invocation_id>/`. These are local evidence locators, not uploaded artifacts. The provider probes do not establish signing, notarization, hosted certification, or publication.
