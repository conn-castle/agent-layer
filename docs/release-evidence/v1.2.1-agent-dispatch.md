## Limitations and known issues

- Antigravity was not validated for this release because the local account quota is exhausted. It passed the same probes for v1.2.0 with CLI `1.5.3`; it now reports `1.5.4`.
- Muse continuation failed once, in pre-launch baseline recovery (#526). The Muse fresh path passed. The failing code is unchanged since v1.2.0, where both Muse probes passed with CLI `1.4.14`.
- These short probes do not establish expired-credential refresh for Grok ([#421](https://github.com/conn-castle/agent-layer/issues/421)) or the cause of earlier unclassified shutdown failures ([#430](https://github.com/conn-castle/agent-layer/issues/430)).
- These probes do not exercise the #523 MCP image handoff. That handoff is covered by the real-image freshness tests, the launcher test that checks the pinned server runs under `images/`, and a manual check that a pinned `al dispatch mcp-server` ran from `images/<sha256>/al`.

Raw probe logs and the options output are kept locally in `.agent-layer/tmp/release-v1.2.1/`. Invocation records live under `.agent-layer/tmp/runs/<invocation_id>/`. These are local evidence locators, not uploaded artifacts. The provider probes do not establish signing, notarization, hosted certification, or publication.
