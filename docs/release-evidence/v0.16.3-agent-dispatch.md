## Fresh and continuation probes

then `al dispatch wait <handle>`. Each continuation used `al dispatch continue
<handle> --prompt <token>`, then `al dispatch wait <handle>`. Every wait
returned `state: completed`, and the corresponding terminal result file
contained exactly the requested token.

## Safe Antigravity missing-ID behavior

`go test ./internal/agentdispatch -run
'TestAntigravity(SuccessfulAnswerWithoutIDIsNotResumable|ResumeWithoutParsedIDRetainsDurableMapping|LogIDIsStrictAndVersionGateFailsLoudly)$'
-count=1` passed on this checkout. The changed or missing UUID-line fixtures
retain the provider diagnostics and mark the conversation `not resumable`; they
do not query global or provider-private session state. The live Antigravity
fresh probe also retained its provider log and was marked `not_resumable` when
its conversation ID could not be safely parsed.
