## Fresh and continuation probes

Each available provider received a fresh `start`/`wait` probe. Providers that
completed it then received a `continue`/`wait` probe on the same handle. The
terminal result files contained exactly the requested tokens.

| Provider | Handle | Fresh result | Continuation result | Result |
| --- | --- | --- | --- | --- |
| Claude | `wide-linear-transformer` | OAuth session expired and could not be refreshed | Not run | Waived after a good-faith attempt |
| Codex | `nimble-gentle-relay` | `START_OK codex` | `CONTINUE_OK codex` | Pass |
| Antigravity | `big-rapid-relay` | `START_OK antigravity` | `CONTINUE_OK antigravity` | Pass |
| Grok | `micro-linear-rectifier` | `START_OK grok` | `CONTINUE_OK grok` | Pass |

`dispatch_options` reported all four providers available. Claude subsequently
failed during `wait` because its external OAuth session had expired and could
not be refreshed. The release owner authorized publishing after a good-faith
attempt if an external roadblock remained, so the missing Claude continuation
probe was explicitly waived rather than reported as a pass.
