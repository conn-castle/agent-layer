# Agent Dispatch v0.21.1 Compatibility Evidence

Date: 2026-09-18

Runner: local macOS checkout using a source build from the v0.21.1 candidate
commit. Provider probes ran in an isolated scratch repository so provider tools
could not modify the release checkout.

## Installed versions

- Claude Code: `2.1.274 (Claude Code)`
- Codex CLI: `codex-cli 0.155.0`
- Antigravity: `1.2.7`
- Grok CLI: `grok 1.0.24 (68e414c661e3) [stable]`

`al dispatch options` reported all four providers available. The configured
source-built targets were Codex `gpt-6-astra` with medium reasoning, Claude
`opus[1m]` with high reasoning, Antigravity `gemini-3.8-flash-high`, and Grok
`grok-4.6` with high reasoning.

Assigned conversation names used the expanded three-element pool, including
non-size adjectives, colors, and additional electrical parts
(`tiny-black-led`, `micro-even-battery`, `short-still-stator`,
`short-peppy-comparator`).
